The key lesson: if I'm setting a 2.82:1 R:R swing target, my trailing stop needs to accommodate swing-sized volatility, not scalp-sized noise. A 1-minute exit on a setup targeting $2020 means my trail was misaligned with my thesis. Next time: either commit to the scalp (tight trail, small target) OR commit to the swing (wider trail, let it breathe). Don't set swing targets then use scalp exits — that's how you cut winners short while letting losers run their full stop distance.
