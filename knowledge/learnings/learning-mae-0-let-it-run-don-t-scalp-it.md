When you get a perfect entry (MAE $0.00), that's a signal to INCREASE conviction, not take quick profits. My trailing stop was configured for failure — too tight for crypto volatility, too quick for a leveraged position. New rule: if MAE stays under 0.1% for the first 2 minutes, widen the trailing stop and aim for 2%+ on 10x positions. Also: document the actual setup BEFORE entering. 'Let's see if this holds up' isn't a thesis.
